Cuando te pida implementar algo:
1. Primero explora el código existente del servicio relevante
2. Identifica el patrón en uso (hexagonal o MVC)
3. Sigue exactamente las convenciones del servicio existente
4. Genera código completo y funcional, no pseudocódigo
5. Incluye validaciones, manejo de errores con @ControllerAdvice
6. DTOs separados de entidades
7. Inyección por constructor

Para frontend:
1. Componentes funcionales con hooks
2. Tailwind CSS
3. Servicio Axios con mock incluido
